# Tagalog quick-chat clips

`0.mp3` through `3.mp3` say “Tara G”, “Aray mo”, “Lala”, and “Hehe”.
These Filipino (tl) synthesized voice clips were rendered with Google Translate
speech on 2026-10-25 and are bundled for playback without a runtime speech service.
Character playback varies slightly in pitch. Browser speech is a fallback only
when a Filipino/Tagalog voice is installed; English voices are never substituted.
