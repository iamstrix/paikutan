1. What you need

  • A laptop or PC with Chrome or Edge (the host / spectator screen).
  • Two phones with a browser (Chrome on Android, Safari on iPhone).
  • Internet on all three devices (Wi-Fi or mobile data).
  • Python 3 (only for running on your own PC).
  • Git and a GitHub account (for deploying).

Why GitHub Pages and not localhost: phones only allow motion sensors (flick and tilt) on HTTPS pages. A laptop address like http://192.168.x.x is not HTTPS, so flick and tilt would be blocked. GitHub Pages gives HTTPS for free, and judges can open the link from anywhere.

2. Run on your PC

  1. Open a terminal in the project folder: 
    cd C:\dev\Antigravity\level-up-2
  2. Start a local web server: 
    python -m http.server 8000
  3. Open http://localhost:8000/index.html in Chrome.
  4. Click Practice vs CPU to play with the mouse and keyboard.

Note: opening index.html by double-clicking it will not work. The game must be served by a web server.

3. Test without internet (one PC, three tabs)

  1. Start the local server (step 2).
  2. Open http://localhost:8000/index.html?net=local and click Host a match.
  3. Click the join link under the QR code. It opens play.html?room=XXXX&net=local.
  4. Open that same join link in a second tab.
  5. Join with a different name in each tab. The match starts when both players have joined.

Each tab counts as a separate player. On a PC there are no motion sensors, so swipe up to throw and drag the round pad to steer.

4. Deploy to GitHub Pages

  1. Create a new public repository on GitHub (for example paikutan). Do not add a README.
  2. In the project folder: 
    git init
git add .gitignore README.md setup.html package.json index.html play.html css/style.css js/
git commit -m "Paikutan: trumpo battle game"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/paikutan.git
git push -u origin main
  3. On GitHub, open the repository and go to Settings > Pages.
  4. Under Build and deployment, set Source to Deploy from a branch, Branch to main, folder / (root), then click Save.
  5. Wait 1 to 2 minutes. The game will be at: 
    https://YOUR-USERNAME.github.io/paikutan/

After later pushes, GitHub Pages can take up to about 10 minutes to update. Use Ctrl+Shift+R to hard-refresh.

Do not commit screenshots (image*.png). They are already listed in .gitignore.

Supabase (online rooms)

  • Online rooms use the existing Supabase project ojtswbpzqyuqocdphirz. The settings are in js/config.js.
  • No database tables or SQL migrations are needed. The game only uses Realtime broadcast.
  • Free Supabase projects pause after about a week without use. Before any demo or judging, log in to the Supabase dashboard and make sure the project is active. Restore it if it is paused.

5. Play a real match (laptop + 2 phones)

  1. On the laptop, open the GitHub Pages link and click Host a match. A 4-letter room code and a QR code appear.
  2. Connect the laptop to a TV or projector if available. Press the fullscreen button (bottom right).
  3. Each player scans the QR code with their phone camera, or opens play.html and types the room code.
  4. Each player enters a name and taps Join match.
  5. When the phone asks for motion access, tap Allow. This is required on iPhone.
  6. Turn the phone volume up and keep the screen on.
  7. Both players pick a character and a trumpo, then tap Ready!.

Phone controls

StepWhat to do
Paikot (spin)Draw fast circles on the ring with a finger for 3 seconds. Faster = more spin. Staying on the ring = steadier trumpo.
CountdownHold the phone like a trumpo. Tilt left or right to aim (the arrow shows the aim).
Bitaw (throw)When "BITAW!" appears, flick the phone forward like casting a fishing line. Hold it tightly. If the flick does not register, swipe up fast on the screen.
Laban (fight)Tilt the phone to steer, or drag the round pad at the bottom left. Tap "Re-center tilt" if steering drifts.
PowerTap the round power button at the bottom right when it glows.

Win rules

  • A trumpo loses the round if it topples over (natumba) or leaves the chalk circle (labas).
  • First to win 2 rounds is the Kampeon.
  • If both fall at the same time (tabla), the round is replayed.

7. Event-day checklist

  • [ ] Supabase project is active (not paused).
  • [ ] GitHub Pages link opens and shows the title screen.
  • [ ] Laptop is charged and connected to the TV or projector, and sound is on.
  • [ ] Two test phones are charged and have mobile data in case the Wi-Fi fails.
  • [ ] Motion access was allowed on both phones (test one throw).
  • [ ] Browser zoom is 100% and the page is in fullscreen.
  • [ ] Backup plan: if the internet is down, run index.html?practice on the laptop, or play.html?solo=1 on a phone.
  • [ ] Backup video: the gameplay video is ready on the laptop.

8. Troubleshooting

The page is blank or shows nothing
The game must be served from a web server (GitHub Pages or python -m http.server). Double-clicking the file does not work. It also needs internet the first time to load three.js and the fonts.
"Could not connect" on the host or phone
Check the internet connection. Check that the Supabase project is not paused. To test without internet, use ?net=local on one PC.
The flick does not throw
Make sure motion access was allowed. On iPhone, reload the page and tap Join again to get the permission prompt. Flick harder, or swipe up fast on the screen instead. If the trumpo is not thrown within 3 seconds, it is thrown weakly by itself.
Tilt steering does not work or drifts
Tap Re-center tilt while holding the phone comfortably. Or use the round drag pad at the bottom left.
"This room already has two players"
The room is full. On the host, click Cancel and then Host a match again to make a new room.
A phone disconnected mid-match
Reload the phone page and join the same room again from the same browser tab. If that fails, cancel on the host and make a new room.
No sound
Browsers only play sound after the first tap or click. Click anywhere on the host page. Check the mute button (bottom right) and the phone's silent switch.
Changes do not show on GitHub Pages
Wait up to 10 minutes after pushing, then hard-refresh with Ctrl+Shift+R.
