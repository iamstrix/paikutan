Arena Zones: "Swerte!" & "Madulas!"

Introducing dynamic barangay street hazards: the Tae ng Ibon (Bird Droppings) healing zone and the Ihi ng Aso (Dog Puddle) low-friction drift hazard.

1. Concept & Cultural Lore

Playing trumpo on a Philippine street or basketball court means dealing with the living chaos of the barangay. Adding interactive arena zones brings comedic authenticity and tactical comeback depth to the circle:

🪶 Tae ng Ibon ("Swerte!")

+Spin / Heal

The Filipino Superstition: In the Philippines, getting droppings on you from an overhead bird (maya or kalapati) is famously considered "Swerte" (good luck: "Uy swerte yan, tumaya ka sa lotto!").

Tactical Role: A comeback lifeline. When your trumpo is low on spin or wobbling toward collapse, diving into the white splatter restores RPM, resets gyro wobble, and recharges your special ability.

🐕 Ihi ng Aso ("Madulas!")

Low-Friction Slip

The Stray Dog Lore: The game already features the iconic Asong Gala charging across the arena in sim.js. As the dog pauses at the edge or charges across, it occasionally marks its territory, leaving a slick puddle.

Tactical Role: Area denial and drifting. Rolling into the puddle drops ground grip by 85%. The top drifts along its existing vector, making it easy to knock opponents straight out of the ring (Labas!).

3. Simulation Physics Integration (sim.js)

Both zones are handled in the authoritative physics tick inside sim.js, maintaining determinism between local and network play.

Data Model in World State

// Inside world state w
w.zones = [
  {
    id: ++w.zoneId,
    type: 'swerte',     // 'swerte' | 'ihi'
    x: 0.45,            // world coordinate X
    z: -0.80,           // world coordinate Z
    r: 0.75,            // radius in meters
    t: 0,               // elapsed time
    life: 6.5           // lifetime in seconds
  }
];

Per-Tick Top Collision & Response

// In sim.js update(w, dt) loop for each live top tp:
for (const zone of w.zones) {
  const d = Math.hypot(tp.x - zone.x, tp.z - zone.z);
  if (d >= zone.r + TOP_R * 0.5) continue;

  const overlap = 1 - d / (zone.r + TOP_R * 0.5);

  if (zone.type === 'swerte') {
    // 1. Replenish spin
    tp.spin = Math.min(1.0, tp.spin + 0.16 * dt * overlap);
    // 2. Dampen wobble / gyro stabilization
    tp.wobble = Math.max(0, tp.wobble - 0.35 * dt * overlap);
    // 3. Ability gauge recharge
    tp.charge = Math.min(1.0, tp.charge + 0.12 * dt * overlap);
    
    if (w.t - (tp.lastSwerteAt || 0) > 0.4) {
      tp.lastSwerteAt = w.t;
      ev(w, 'swerteHit', { slot: tp.slot, x: tp.x, z: tp.z });
    }
  } else if (zone.type === 'ihi') {
    // 1. Drastic steering loss (only 15% grip)
    gripMod *= 0.15;
    // 2. Near-zero surface friction (momentum carries top)
    frictionMod *= 0.12;
    // 3. Slight wobble jitter from unsteady ground
    tp.wobble = Math.min(0.9, tp.wobble + 0.08 * dt * overlap);

    if (w.t - (tp.lastSlipAt || 0) > 0.35) {
      tp.lastSlipAt = w.t;
      ev(w, 'slipHit', { slot: tp.slot, x: tp.x, z: tp.z });
    }
  }
}
Network Efficiency Note: Zones are serialized into snapshot(w) as compact 5-element arrays: [typeCode, x, z, radius, remainingTime]. This consumes less than 35 bytes per snapshot over Supabase Realtime broadcast channels.

4. 3D Graphics & Decal Rendering (scene.js)

Ground marks use lightweight Three.js PlaneGeometry decals positioned at y = 0.018 to avoid z-fighting with the arena dirt plane. Textures are procedurally painted onto canvases using canvasTex(): 

// Procedural canvas textures in scene.js
const swerteTex = canvasTex(128, 128, (g, w, h) => {
  const cx = w / 2, cy = h / 2;
  // White splash lobes
  g.fillStyle = 'rgba(255, 255, 245, 0.92)';
  [[0,0,30],[18,14,16],[-16,12,14],[12,-16,18],[-14,-14,12]].forEach(([ox,oy,r]) => {
    g.beginPath(); g.arc(cx + ox, cy + oy, r, 0, Math.PI * 2); g.fill();
  });
  // Organic dark core
  g.fillStyle = 'rgba(65, 70, 55, 0.85)';
  g.beginPath(); g.arc(cx - 2, cy - 2, 12, 0, Math.PI * 2); g.fill();
  // Golden lucky halo fringe
  g.strokeStyle = 'rgba(255, 215, 0, 0.75)'; g.lineWidth = 4; g.stroke();
});

const puddleTex = canvasTex(128, 128, (g, w, h) => {
  const cx = w / 2, cy = h / 2;
  const grad = g.createRadialGradient(cx, cy, 6, cx, cy, 52);
  grad.addColorStop(0, 'rgba(240, 195, 30, 0.75)');
  grad.addColorStop(0.7, 'rgba(215, 165, 20, 0.4)');
  grad.addColorStop(1, 'rgba(180, 140, 10, 0)');
  g.fillStyle = grad;
  g.beginPath();
  for (let a = 0; a < Math.PI * 2; a += 0.2) {
    const r = 42 + Math.sin(a * 5) * 6 + Math.cos(a * 7) * 4;
    const px = cx + Math.cos(a) * r, py = cy + Math.sin(a) * r;
    if (a === 0) g.moveTo(px, py); else g.lineTo(px, py);
  }
  g.closePath(); g.fill();
});

5. WebAudio Recipes & Host Commentary

Following the project's zero-dependency WebAudio architecture, all sound cues are synthesized in real time via audio-runtime.js:

Audio Synthesis

  • Bird Dropping ("Splat"): Rapid frequency drop (320 Hz → 70 Hz in 80ms) + bandpass noise pop.
  • Swerte Chime: Bright ascending pentatonic chimes (880, 1108, 1320, 1760 Hz) with soft decay.
  • Dog Puddle Splash ("Dulas"): Low damp squeal with rapid wet flutter when wheels/tips skid.

Host Commentary Lines (host.js)

  • Bird Splat: "May dumaang kalapati! Ingat sa ulo!"
  • Swerte Heal: "Swerte! Juan gets blessed with extra spin!"
  • Dog Piss: "Ay naku! Umihi pa ang asong gala sa bilog!"
  • Madulas Slip: "Dulas! Maria is sliding out of control!"

6. Open Design Decisions for Implementation

  1. Spawn Frequency: Should hazards appear guaranteed every round (e.g. bird drop at ~4s, dog at ~8s), or have a 50% random chance to keep matches varied?
  2. Dog Puddle Location: Should the puddle appear right where the dog pauses at the edge during the countdown, or dropped midway across its charging path?
  3. Visual Aesthetic: Do you prefer a stylized organic splatter with glowing gold aura, or a comical cartoon splash effect?
