# Audio drop-in folder

The game already makes every sound with zero files: SFX and the ambience bed are synthesized, and voice lines fall back to the browser's speech voice. Files you drop here replace those automatically. No code changes needed.

## Ambience (optional)

| File | What | Where to get it |
|---|---|---|
| `ambience.mp3` | One seamless barangay loop, 30–90 s: roosters, distant dogs, a tricycle passing, faint videoke, wind in coconut leaves | Mix from CC0 clips on freesound.org (filter: *Creative Commons 0*), or record it in your own barangay |

## Voice barks (recommended: record your classmates)

Record each line as a short `.mp3` in `barks/`. Local accents sell the nostalgia better than any library.

| File | Line |
|---|---|
| `barks/tara.mp3` | "Tara, laro!" |
| `barks/sablay.mp3` | "Ay, sablay!" |
| `barks/daya.mp3` | "Daya mo!" |
| `barks/galing.mp3` | "Ang galing!" |
| `barks/hala.mp3` | "Hala ka!" |
| `barks/talo.mp3` | "Talo ka na!" |
| `barks/isa.mp3` | "Isa!" |
| `barks/dalawa.mp3` | "Dalawa!" |
| `barks/tatlo.mp3` | "Tatlo!" |
| `barks/uwi.mp3` | "Hoy! Uwi na!" (a lola/nanay calling the kids home) |

Keep them under 2 seconds, trimmed tight. Credit any CC-BY sources in the project README.
